# PF03 - TDD + Node + CI

Proyecto de práctica de TDD (Red → Green → Refactor) con Node.

## Funciones

- `fibonacci(n)`: devuelve el n-ésimo número de la sucesión de Fibonacci.
- `esPinValido(pin)`: valida un PIN de 4 o 6 dígitos que no tenga todos los dígitos iguales.

## Ejecutar los tests

    npm test
